# 🔥 지옥키우기 (BuildHell)

염라대왕의 신참 옥졸이 되어 죄인에게 형벌을 집행하고, 거둔 영혼으로 지옥을 넓혀 가는 Flutter 방치형(클리커) 게임.

## 게임 방법

- **형벌 집행** — 가운데 가마솥 영역 아무 곳이나 터치하면 영혼 👻 획득
- **🔥 지옥** — 영혼으로 지옥을 개방/확장하면 초당 영혼 자동 생산
  - 발설지옥 → 독사지옥 → … → 무간지옥까지 11단계
  - Lv.10 / 25 / 50 / 100 / 150 / 200 / 300 / 400 / 500 달성 시 해당 지옥 생산량 x2
  - x1 / x10 / x100 / MAX 일괄 구매
- **🔱 강화**
  - 형벌 도구 강화: 터치 위력 증가 (+ 초당 생산량 일부를 터치에 추가)
  - 악마 교관 고용: 전체 생산량 +25%/Lv
  - 저승사자 증원: 탈옥수 출현 빈도·포상 증가
  - 저승 장부: 오프라인 수익 최대 시간 +2시간/Lv (윤회해도 유지)
- **🏃 탈옥수** — 가끔 화면에 나타나는 탈옥수를 8초 안에 잡으면
  큰 포상금 또는 **지옥불 폭주**(20초간 모든 생산 x7)
- **☸️ 윤회** — 이번 생 누적 영혼 100만부터 가능. 진행을 초기화하는 대신
  업보(= √(누적영혼/100만))를 얻어 영구히 생산량·터치 +10%/업보
- **오프라인 수익** — 앱을 꺼둔 동안 생산량의 50% (기본 최대 4시간)
- 진행은 자동 저장 (10초마다 + 앱이 백그라운드로 갈 때)

## 실행

```bash
flutter pub get
flutter run            # 연결된 기기/에뮬레이터
flutter run -d chrome  # 웹
flutter test           # 로직·위젯 테스트
```

## 구조

```
lib/
  main.dart               앱 진입점 (저장 불러오기)
  game/
    data.dart             지옥·강화·칭호 데이터 (밸런스 수치는 여기서 조정)
    game_state.dart       게임 로직 (생산, 구매, 탈옥수, 윤회, 오프라인, 직렬화)
    numbers.dart          한국식 큰 수 표기 (만/억/조/경/해…)
    save_service.dart     shared_preferences 저장
  ui/                     화면 (헤더, 터치 영역, 탭 4개)
test/                     로직·위젯 테스트
```
