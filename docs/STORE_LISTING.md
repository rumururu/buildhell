# 스토어 등록 문구 (초안)

## 앱 이름
지옥키우기 - 방치형 지옥 경영

> 출시 전에 Google Play / App Store에서 같은 이름의 앱이 있는지 꼭 검색하세요.

## 짧은 설명 (Google Play, 80자 이내)
신참 옥졸이 되어 죄인을 심판하고 지옥을 키우는 방치형 게임! 탕비실 간식 도둑은 어느 지옥으로?

## 전체 설명
염라대왕의 신참 옥졸로 취직했습니다. 첫 업무는… 지옥 키우기.

🔥 터치 한 번에 형벌 집행
가마솥을 두드려 죄인의 영혼을 거둬들이세요. 가끔 터지는 치명타의 손맛!

⚖️ 오늘의 죄인을 심판하라
"회사 탕비실 간식 상습 싹쓸이", "단톡방 읽씹 1,204회", "영화 개봉 첫날 스포일러 유포"…
죄목에 맞는 지옥으로 보내면 포상, 잘못 보내면 억울한 죄인이 탈옥합니다.

🏯 11개의 지옥을 짓고 확장
발설지옥부터 독사지옥, 화탕지옥, 한빙지옥, 그리고 무간지옥까지.
지옥을 키울수록 영혼이 저절로 쌓입니다. 꺼 둔 동안에도 옥졸들이 일합니다.

🏃 탈옥수를 잡아라
화면을 가로지르는 탈옥수를 잡으면 포상금, 또는 생산량 7배 '지옥불 폭주'!

☸️ 윤회로 더 강하게
처음부터 다시 시작하는 대신 업보를 얻어 영원히 강해집니다.

📅 매일 출석·임무·업적
혼석을 모아 시간의 모래시계, 염라의 인장 등 특별한 아이템을 얻으세요.

## 카테고리 / 태그
- 카테고리: 게임 > 시뮬레이션 (또는 캐주얼)
- 태그: 방치형, 클리커, 키우기, 경영, 캐주얼

## 콘텐츠 등급 참고
- 만화적 표현의 "지옥 형벌" 묘사(혀 뽑기, 톱 등은 텍스트·이모지 수준), 실제 유혈 묘사 없음
- 보상형 광고 포함, 인앱 결제 없음
- IARC 설문에서 "폭력: 만화/판타지" 정도로 응답 → 보통 12세 이용가 예상 (설문 결과에 따름)

## 스크린샷 구성 제안 (5장)
1. 가마솥 터치 + 치명타 장면 — "터치 한 번에 형벌 집행!"
2. 심판석 (웃긴 죄목이 보이게) — "탕비실 간식 도둑은 어느 지옥으로?"
3. 지옥 목록 (여러 개 개방된 상태) — "11개의 지옥을 키워라"
4. 탈옥수 / 지옥불 폭주 — "탈옥수를 잡으면 7배!"
5. 출석·임무·업적 — "매일 받는 혼석"
